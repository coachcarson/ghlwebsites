Wallace Fitness landing page

Two pages, one paste each. Styles, logo, colors and your GHL form are all inside each block.

Page 1 · Landing page

Copy the landing page

In GHL, click the landing page's Custom JS/HTML element and open its code editor. Select everything already in it (Ctrl+A, or Cmd+A on Mac) and delete it. Paste this in, then save the element and save the page.

Page 2 · Thank you page

Copy the thank you page

Make a second page on the same website (path mount-dora-free-consultation-thank-you). Add one Custom JS/HTML element, paste this in, save the element and the page. Then set the form's On Submit to redirect to this page's URL.

The builder canvas may look blank. Check both pages in Preview.
